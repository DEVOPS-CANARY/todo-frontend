# todo frontend

The frontend of the todo sample app, in its own repository (the app is split in one repository per
component, as RSSB's apps are). Code at the root; the platform's golden path adds the pipeline caller
and the Dockerfile through the "Onboard an app" issue in DEVOPS-CANARY/platform-golden-path.
Origin: the `frontend/` folder of DEVOPS-CANARY/todo-app.
